# CodeAlpha_Stock-Portfolio-Tracker

A simple Stock Portfolio Tracker developed using Python as part of the CodeAlpha Python Programming Internship.

## Project Overview

This project is a simple command-line stock portfolio tracker that calculates the total investment based on manually defined stock prices and user-entered stock quantities.

The program uses a Python dictionary to store stock prices and basic arithmetic to calculate the total investment.

## Features

- Manually defined stock prices
- User input for stock name
- User input for stock quantity
- Calculates total investment
- Displays stock price and quantity
- Simple command-line interface
- Beginner-friendly Python program

## Concepts Used

- Python Programming
- Dictionary
- Variables
- `input()` for user input
- `print()` for displaying output
- Basic arithmetic
- String manipulation
- Dictionary indexing
- `int()` function

## How the Program Works

1. The program stores stock names and their prices in a dictionary.
2. The user enters a stock name.
3. The user enters the quantity of the stock.
4. The program gets the stock price from the dictionary.
5. The program multiplies the stock price by the quantity.
6. The total investment is calculated.
7. The program displays the stock name, quantity, price, and total investment.

## Example

```text
Stock Portfolio Tracker 

Enter stock name: AAPL
Enter quantity: 5

Stock: AAPL
Quantity: 5
Price: 180
Total Investment: 900
````
